# Field Notes and Pattern Journal

This folder is for observation-based learning and real-world pattern thinking.

## Purpose

Use this area to document:

- photographs of places, gardens, parks, streets, and public spaces
- notes about what makes a place feel alive, calm, or useful
- links to ideas from Christopher Alexander and pattern-language thinking
- comparisons between lived environments and software design

## Suggested structure

- notebooks/pattern-journal/
  - README.md
  - observer-field-journal-template.md
  - garden/
  - town-square/
  - park/

## Why this is separated

This keeps the code examples in the main pattern folders clean while preserving the observational, reflective layer of the project.

The technical examples remain in the GoF pattern folders, and the notebook becomes a companion to the learning process.
