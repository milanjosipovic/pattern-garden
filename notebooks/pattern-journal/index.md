# Pattern Journal

A place to connect lived experience, architectural thinking, and software patterns through careful observation.

## Purpose

Instead of starting with abstract theory only, begin from the environment itself:

- where do people gather?
- what makes a place feel welcoming?
- what recurring structures create comfort, order, or flow?
- how does a place notify people, guide them, or react to change?

## Pattern lens

Use this journal to explore themes such as:

- threshold
- edge
- center
- enclosure
- path
- public space
- rhythm
- local order
- human scale

## Alexander connection

This journal intentionally follows the way of thinking developed in:

- The Timeless Way of Building
- The Pattern Language

The key question is not only "what is this pattern in code?" but also:

"what recurring pattern is present in the world, and what makes it useful or alive?"

## Suggested workflow

1. Visit a place
2. Take a few photographs
3. Describe what you notice
4. Identify a possible pattern
5. Link it to software concepts such as Observer
6. Write a short reflection
