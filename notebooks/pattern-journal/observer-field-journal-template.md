## Real-world Observer mapping

Translate the situation into Observer-pattern language.

### Subject
The stateful thing that changes.

- Example: central garden controller / town announcement board / park operations system

### Observers
The parties that care about the state change.

- Example: gardeners, kiosks, visitors, staff, alert systems

### Trigger
What makes the subject change?

- Example: moisture drops, event is updated, weather warning issued

### Notification
How is the change communicated?

- Example: signal, display update, message, alert, dashboard update
